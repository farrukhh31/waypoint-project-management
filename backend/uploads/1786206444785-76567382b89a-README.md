# Lumière

A production-style full-stack e-commerce platform for premium skincare &
cosmetics.

## Live Demo

-   Frontend: https://your-vercel-link.vercel.app
-   GitHub: https://github.com/yourusername/lumiere

## Overview

Lumière is a full-stack e-commerce application built with Next.js,
Node.js, Express, PostgreSQL and Prisma. It includes a customer
storefront, admin dashboard, secure REST API, authentication, coupons,
inventory, analytics, and order management.

> **Note:** Card payments are simulated for demo purposes only.

## Installation

``` bash
git clone https://github.com/yourusername/lumiere.git
cd backend
npm install
cd ../frontend
npm install
```

## Environment Variables

Backend:

``` env
DATABASE_URL=
JWT_ACCESS_SECRET=
JWT_REFRESH_SECRET=
CLOUDINARY_CLOUD_NAME=
CLOUDINARY_API_KEY=
CLOUDINARY_API_SECRET=
```

Frontend:

``` env
NEXT_PUBLIC_API_URL=
```
